---
title: "规则与提示词"
---

规则与提示词用于调整 Agent 的工作方式。规则适合长期保持的约定，提示词模板则决定某个 Agent 或后台任务如何理解自己的身份、步骤和输出要求。

## 全局规则与项目规则

于左侧边栏底部打开`设置`，在列表中选择`规则`，再选择全局或某个项目的作用域。

全局规则适用于不同项目中的 Agent；项目规则只在相应作品中加入上下文。你可以为每条规则填写标题和内容，也可以把已有规则复制到另一个作用域。

例如，全局规则可以约定协作方式：

```text
在修改正文前，先说明修改范围与预期效果。
```

项目规则可以约定作品本身的写法：

```text
本项目使用第三人称限知视角，每个场景只跟随一个视角人物。
```

规则会占用上下文，应保持明确、简短，并清理相互冲突的要求。大量背景资料更适合存放在角色、世界书或笔记中，需要时再读取。

## 提示词模板

从应用侧边栏打开`提示词模板`，选择要调整的模板。也可以在`智能体`或`摘要`设置中点击对应链接，直接跳转到相关模板。

模板由多个条目组成，每个条目包含角色、内容、顺序与启用状态。你可以分开组织身份、工作流程、格式要求等指令，再通过顺序与开关控制组合。

<Steps>
  <Step title="选择模板">
    如果要调整 Agent 的行为，选择对应 Agent 的模板；如果要调整章节或区间摘要，选择`记忆`中的对应模板。
  </Step>
  <Step title="修改并保存">
    编辑需要调整的条目，检查角色、顺序与启用状态，再保存更改。未保存的本地修改与已经保存的模板版本是不同状态，离开前请确认。
  </Step>
  <Step title="验证效果">
    使用一个范围较小的实际任务检查结果，观察 Agent 是否按新的要求工作。模板有版本历史，可以查看版本差异，或按界面提供的操作恢复。
  </Step>
</Steps>

重置内置模板会恢复默认内容，执行前请保留自己的修改。修改模板也不会自动重写已有章节或重新生成旧摘要。

## 何时使用 Skill

规则用于持续适用的约束，模板用于定义整体行为，而[技能](/feature/skill)适合某类任务才需要的专业流程，例如对话检查或人物设计。

如果一份指令很长，却只在少数任务中使用，可以把它整理成 Skill，并将详细资料放进参考文档，按需加载，减少每轮请求的上下文负担。

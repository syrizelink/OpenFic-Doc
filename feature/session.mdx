---
title: "会话"
---

会话是你与 Agent 协作的工作记录，包含消息、工具调用、提问、审批和内容变更。一个项目可以保留多个会话，你可以按任务将资料整理、剧情规划与正文修改分开进行。

## 开始会话

在项目工作区打开会话区，选择主 Agent 和语言模型，再输入任务。Build 适合直接推进多数写作任务，Plan 适合先分析需求、组织计划，再调度子 Agent。

模型需要支持工具调用。若只创建了提供商而没有可用模型，请先完成[模型配置](/getting_started/model)。

### 引用项目内容

在输入框中输入`@`可以检索并引用项目中的卷、章节、笔记、角色或世界书条目。也可以打开引用与内容菜单，选择对应类型后查找。

<Frame caption="通过输入框菜单添加引用、附件或技能；示例消息尚未发送。">
  ![会话输入框中打开引用与内容菜单，显示图片、文件、技能与内容入口](/images/screenshot/session-references.png)
</Frame>

引用能够帮助 Agent 定位具体内容。与其只说“修改那段对话”，更推荐引用相关章节，并说明人物、位置与修改目标。

输入`/`则可以引用已启用的 Skill，参阅[技能](/feature/skill)。

### 添加附件

你可以添加图片或文件作为当前任务的材料。图片需要当前模型支持图片输入；文档会由后端解析为可供 Agent 读取的内容。

常见支持格式包括 TXT、Markdown、PDF、CSV、DOCX、HTML，以及部分 Office 和电子书格式。单个附件最大 10 MB，每条消息最多 20 个附件，是否能成功提取内容还取决于文件本身和解析器。

<Note>
  文件解析不等同于保留原始排版，也不保证能够识别扫描版 PDF 中的文字。附件上传后不会自动变成项目章节或笔记；需要导入正文时，请使用主页的导入功能。
</Note>

## 处理提问与工具审批

当 Agent 需要补充信息时，会显示提问面板。你可以选择预设选项或自行输入回答；如果选择忽略，Agent 将按工具返回的状态继续处理。

工具权限设为`询问`时，Agent 会暂停并显示审批面板。检查工具名称和参数后，选择执行或拒绝。折叠面板只会收起显示，不会自动完成审批。

这些权限在`设置`中的`工具权限`统一管理，参阅[智能体](/feature/agent)。

## 查看子 Agent

主 Agent 委派任务后，会话中会显示对应的子 Agent 及状态。你可以打开子会话查看消息、任务进度和工具调用。

子 Agent 使用自己的能力、模型与 Skill 配置。若某个任务无法被委派，请检查主 Agent 的`可委派智能体`列表，以及目标子 Agent 是否启用。

## 中断与继续

任务运行时，可以点击`停止`中断当前执行。会话因取消或异常结束，且保留了可恢复状态时，可以使用`继续`从原状态推进。

如果不存在可恢复的检查点，或界面没有提供继续入口，可以发送一条新消息说明要接续的任务。继续会话并不意味着之前已经执行的内容变更会被撤销。

历史消息较多时，会话会分段加载，你可以向上查看更早的记录，或通过消息导航定位。浏览器中断连接后，返回会话时应先确认任务当前状态，避免重复提交同一项修改。

## 检查内容变更

一轮工作完成后，可以查看本轮更改摘要；打开`会话更改`，则可以比较整个会话对章节、笔记、角色和世界书条目的修改。

差异视图可以切换统一或拆分显示，并按需展开内容。请在这里检查重要改动，再继续下一轮协作。

### 回滚与分叉

有可用版本与检查点信息的用户消息可以执行回滚或分叉。回滚会恢复到该消息发送前的状态；分叉则从对应节点创建新的任务分支，以探索另一种写法。

<Warning>
  回滚会改变作品内容，执行前请检查确认面板中的影响范围，并备份需要保留的后续修改。旧会话缺少版本或检查点信息时，可能无法回滚或分叉；迁移数据库后也可能失去这些能力，参阅[迁移到 PostgreSQL](/postgre-sql)。
</Warning>

## 通知

在`设置`中的`通知`启用系统通知后，可以在 Agent 完成任务或等待处理时收到提醒。首次使用可能需要浏览器或系统授权，也可以发送测试通知检查是否可用。

你还可以选择仅在窗口未聚焦时通知。若无法收到通知，请检查操作系统的通知权限与勿扰设置。

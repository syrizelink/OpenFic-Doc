title: "语音转写"
---

<Note>
  本功能已加入当前仓库，计划随 0.13.0 发布，目前尚未正式发布。
</Note>

语音转写可以将录音转换成文字，供你在 Agent 会话中继续编辑或直接发送。识别使用的 ASR 服务独立于聊天模型，切换语言模型不会改变语音配置。

## 选择识别方式

于左侧边栏底部打开`设置`，在列表中选择`语音转写`，再选择 ASR 提供商。

| 方式 | 特点 |
| :-- | :-- |
| Sense Voice (本地) | 在 OpenFic 后端所在设备上运行，模型准备完成后可离线识别 |
| OpenAI / OpenAI compatible | 使用 OpenAI 或兼容的音频转写接口 |
| Groq、Mistral、Deepgram | 使用相应服务商的语音识别服务 |
| Azure Speech | 使用 Azure 语音服务，需要对应资源的密钥和服务地址 |

选择本地方式时，音频会发送给你的 OpenFic 后端处理；选择云端方式时，后端还会将音频提交给所选服务商。

## 准备 SenseVoice 模型

<Steps>
  <Step title="选择本地模型">
    将 ASR 提供商设为`Sense Voice (本地)`，然后点击`准备模型`。

    系统会下载约 241 MB 的 INT8 SenseVoice Small、词表与 Silero VAD 文件，并校验完整性。下载与识别都发生在后端设备上，请确保该设备可以访问下载源且有足够存储空间。
  </Step>
  <Step title="等待准备完成">
    界面会显示选择下载源、下载、校验等进度，等待状态变为`已就绪`后再开始识别。下载失败时可以重试，已经校验通过的文件会被复用。

    如果已经离线下载了模型，可以展开`自定义模型路径`，分别填写 ONNX 模型、词表和 VAD 文件在后端设备上的绝对路径。Docker 中应填写容器内可访问的路径。
  </Step>
  <Step title="设置语言">
    使用`auto`自动识别，或指定`zh`、`en`、`yue`、`ja`、`ko`。保存设置后即可返回会话使用。
  </Step>
</Steps>

## 配置云端服务

选择服务商后，填写 API Key，并按需调整 API 基础地址、模型和识别语言。基础地址与模型留空时使用该服务商的默认值；兼容服务请填写它实际提供的音频接口基础地址。

Azure 使用完整语言代码，例如`zh-CN`或`en-US`，也可以使用`auto`。其他服务的语言与模型支持范围，请以提供商说明为准。

语音服务的密钥不会自动复用`提供商`页面中的聊天模型密钥，需要在这里单独填写。已保存的密钥会在后端加密保存；不修改时保留原值，删除密钥操作在保存后生效。

## 在会话中使用

点击 Agent 输入框中的录音按钮并允许使用麦克风。录音期间会显示实时波形，你可以选择：

- `停止并识别`：将识别结果插入输入框，检查并修改后再发送。
- `转写并发送`：识别成功后，将结果与输入框中已有的草稿合并，再按当前会话的发送流程提交。
- 取消或按`Esc`：结束当前录音操作。

单次录音最长约 5 分钟，达到时限后会自动停止并识别。选择`停止并识别`时，转写结果也会追加到输入框中已有的草稿后，请检查完整内容后再发送。

<Tip>
  浏览器录音通常需要 HTTPS 或`localhost`，并且已授予麦克风权限。如果使用手机通过普通 HTTP 局域网地址访问，可能无法录音，可以改用 HTTPS 地址。
</Tip>

识别失败时，请先检查音频时长、浏览器权限、模型准备状态或云端服务配置。录音被保留且界面允许重试时，可以重新识别，无需立刻重新录音。

---
title: "摘要"
---

摘要用于概括章节与一段章节范围的内容，帮助 Agent 理解前文进展。章节摘要记录单章信息，区间摘要进一步聚合多个章节的内容，适合长篇作品。

## 配置摘要模型

于左侧边栏底部打开`设置`，在列表中选择`摘要`。

`摘要模型`默认选择轻量模型，也可以改为默认模型或单独指定的语言模型。生成前请确认对应模型已配置且可调用，参阅[创建模型](/getting_started/model)。

摘要需要调用语言模型，会产生相应的 Token 用量与费用。目标字数影响输出粒度，但不是严格的字数上限。

## 自动生成

| 配置项 | 用途 |
| :-- | :-- |
| 自动生成章节摘要 | 为符合条件的新章节安排章节摘要生成 |
| 自动生成区间摘要 | 在章节摘要处理完成后，为满足条件的范围生成区间摘要 |
| 章节字数阈值 | 低于该字数的章节跳过自动生成，设为`0`表示不跳过 |
| 摘要批次大小 | 控制每批处理的章节数量，实际并发仍受提供商限流约束 |
| 区间摘要章节数 | 决定一个区间覆盖多少章，数量越多，概括粒度通常越粗 |
| 章节 / 区间摘要目标字数 | 通过提示词约束摘要长度 |

在导入较长作品或批量补全摘要时，可以先使用较小批次，观察速度、费用和服务商限流，再按需要调整。

## 查看与维护

在工作区的摘要面板中，可以查看章节摘要与区间摘要的处理状态，并按面板提供的入口生成、重新生成或清理。

正文经过较大修改后，请检查相关摘要是否仍准确。摘要记录的是生成时的内容，不能用它代替核对最新正文；前后文一致性检查需要时仍应让 Agent 读取原文。

<Warning>
  调整会影响区间聚合范围或来源的设置时，系统会提示清理已有区间摘要。确认后会删除所有项目的相关区间摘要，需要按新配置重新生成，请先查看影响范围。
</Warning>

## 修改摘要提示词

在摘要设置中，可以通过提示词链接跳转到`提示词模板`中的`记忆`分类，分别修改章节摘要和区间摘要模板。

你可以要求模型优先记录事件、人物状态、伏笔与时间变化，再通过目标字数控制粒度。修改模板后，需要重新生成对应摘要才能反映新的要求。

如果需要整理当前对话历史，请使用[上下文管理](/feature/context)中的压缩功能；如果希望按语义查找具体段落，请使用[索引](/feature/index)。

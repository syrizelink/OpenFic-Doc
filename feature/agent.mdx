---
title: "智能体"
---

智能体（下称 Agent）是专门的 AI 助手，在创建一个 Agent 会话并开始与 AI 对话时，本质上是与所选的 Agent 进行交互，通过对 Agent 的各个方面进行配置，能够让 Agent 更好的执行某些工作。

## 了解 Agent

在 OpenFic 中，所有 Agent 都被分为两种类型：

- 主 Agent：直接与你交互的 AI 助手
- 子 Agent：由主 Agent 调用，执行某些专业任务的 AI 助手

一般的，Agent 由模型、提示词、能力和技能四个部分构成，在 OpenFic 中，你可以简单、自由的通过 GUI 配置所有部分，而不需要了解繁琐的文件结构。

其中，模型是驱动 Agent 运行的核心，模型的能力决定了 Agent 能力的上限，但出于成本和质量考量，为不同的 Agent 分配适合其任务类型的模型是很有必要。

提示词是指导 Agent 完成任务的命令，Agent 通过提示词认识自己的身份、任务以及需要完成的工作，并遵从提示词运行，高质量、准确的提示词会在很大程度上影响 Agent 完成任务的质量。

能力是指分配给 Agent 允许其使用的工具合集，每一个能力中都包含了一个或多个工具，通过使用工具，Agent 才能够与实际内容交互，譬如查找、读取或是修改。

技能是专用于特定任务的指令，有关技能的详细信息，参见 [技能](/feature/skill)。

## 主 Agent

在 OpenFic 中，主 Agent 承担着直接处理用户消息并与你交互的任务，此外，它还需要在必要时协调和组织 Agent 共同推进目标。

除了上述提到过的四个共同部分不再赘述以外，还有一些部分是主 Agent 所独有的。

主 Agent 本质上可以算作一个模式（Mode），这是因为在 Agent 侧边栏中，你可以选择使用特定的主 Agent，而每个都有其独特的标识，你可以通过设置`颜色`和`图标`来个性化自定义主 Agent。

你还可以撰写一份简要、清晰的描述，以便在打开选择器时，快速阅览并了解这一主 Agent 能够胜任什么任务、适合完成什么工作。

标识的目的是为了在主 Agent 的数量较多时，帮助你快速的识别并找到它们，对于不同任务使用其专用的 Agent 能够大大提高效率，并减少不必要的沟通。

此外，主 Agent 还具备两项独特的能力，即`委派子任务`和`提问`。

委派子任务即允许委派子 Agent 进行工作，在勾选这一能力后，在`可委派智能体`部分可以选择所要允许主 Agent 使用的特定 Agent。

在构建上下文时，只有勾选的子 Agent 才会被主 Agent 获知并有依据的委派，这意味着它并不能委派未启用的子 Agent，即使主动要求其委派，也会由于未勾选而返回错误。

提问即允许主 Agent 主动向你提出问题以获取更多信息，在工作过程中，实时与用户的需求和观点同步是十分重要的，这保证了 Agent 在执行任务（尤其是那些复杂、长程的任务）时不偏离正确的方向。

## 子 Agent

子 Agent 的大多数设置与主 Agent 相同，不过`描述`这一项对其尤为重要。

在主 Agent 决定如何委派子 Agent 时，描述会被传递在上下文中对其可见，因此，清晰明确的表述以帮助其准确理解 Agent 的能力，以及应该在何时使用它是很重要的。

由于`描述`将作为提示词的一部分注入上下文中，你也可以在这里进行一些关于相应子 Agent 的额外说明，比如何时不应该使用它、何时应该回收它等。

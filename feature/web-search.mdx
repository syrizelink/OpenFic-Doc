---
title: "联网搜索"
---

联网搜索可以让 Agent 查找写作资料、核对事实或获取近期信息。它与语言模型提供商是两套独立配置，连接聊天模型并不意味着已经启用搜索。

## 配置搜索服务

<Steps>
  <Step title="进入联网搜索设置">
    于左侧边栏底部打开`设置`，在列表中选择`联网搜索`，开启`启用联网搜索`。
  </Step>
  <Step title="选择提供商">
    当前支持 Brave、DDGS、Exa、Jina、Perplexity、SearXNG、Serper、Tavily 和智谱等搜索服务。

    需要 API Key 的服务请在这里单独填写。DDGS 可以选择检索后端，SearXNG 需要可用的实例地址，其他提供商也可能有专用配置项。

    <Note>
      DeepSeek 搜索已加入当前仓库，计划随 0.13.0 发布，目前尚未正式发布。使用时需要在联网搜索设置中填写 DeepSeek API Key，单次搜索查询最长 128 个字符。
    </Note>
  </Step>
  <Step title="保存并测试">
    按需调整搜索结果数量与域名过滤列表，点击`保存`。然后在会话中让 Agent 搜索一个具体主题，并检查返回的来源是否符合预期。

    搜索发生在 OpenFic 后端，请确保服务端能够访问所选搜索服务。
  </Step>
</Steps>

## 允许 Agent 使用搜索

进入`设置`中的`智能体`，确认需要搜索的 Agent 已装载相应的联网能力，同时检查`工具权限`中的搜索工具没有被拒绝。

只启用搜索服务，而没有给 Agent 分配能力，或将工具权限设为拒绝，仍然无法完成搜索。子 Agent 也需要自己的能力配置。

## 读取网页

搜索结果通常包含标题、链接与摘要。需要更完整的信息时，Agent 可以继续读取网页内容，而不必只根据搜索摘要判断。

网页能否成功读取取决于目标站点，有登录要求、反爬限制或依赖大量脚本渲染的页面，可能无法提取完整内容。重要事实应结合原始来源核对。

## 网络与域名配置

`域名过滤列表`用于过滤不希望出现在搜索结果中的域名，填写后请检查实际结果是否仍然足够相关。

如果服务端需要通过代理联网，可以按实际部署情况开启`信任代理环境`，让搜索和网页读取使用`HTTP_PROXY`等环境变量。

默认网页读取会防止访问本地或内网地址。`绕过 SSRF 防护`会允许这些访问，只应在明确需要且可信的环境中开启；普通互联网资料检索通常不需要修改它。

搜索服务可能单独计费或限流。遇到认证错误、超时或空结果时，请检查该搜索服务的配置与网络，而不只是更换聊天模型。

---
title: "角色与世界书"
---

角色与世界书用于维护作品中需要反复查阅的设定。它们和章节、笔记一样属于项目，Agent 可以通过工具读取或修改，以帮助你保持长篇创作的一致性。

## 管理角色

进入项目中的角色页面，创建角色并填写姓名、简介以及需要长期维护的资料。你可以添加头像，并在角色内容中记录经历、性格、外貌、目标和人物关系。

相比把所有人物放进一段提示词，按角色分别维护更方便查阅和更新。角色较多时，可以通过搜索定位相关人物。

<Frame caption="将人物经历、性格与目标分别维护在角色资料中。">
  ![示例项目中的角色列表与林舟的角色资料编辑器](/images/screenshot/character-editor.png)
</Frame>

设定发生变化后，请同步修改角色资料。尤其是身份揭示、关系转变和动机变化，应明确哪些是初始状态，哪些是当前剧情中的状态，避免混在一起产生歧义。

### 关系图谱

角色关系图谱可以帮助你从整体查看人物之间的联系。先维护角色与关系信息，再切换到图谱查看，适合检查群像作品中的人物网络。

<Frame caption="关系图谱展示已维护的人物关系，节点位置可以按需整理。">
  ![角色关系图谱展示林舟、沈禾、陈伯及旧识、引路人关系](/images/screenshot/character-graph.png)
</Frame>

图谱是设定的展示与管理入口，不会自动保证正文已经符合关系设定。需要检查前文时，可以让 Agent 结合角色与指定章节进行核对。

## 管理世界书

世界书以条目组织地点、组织、力量体系、物品、历史事件等信息。进入项目中的世界书页面，创建条目并填写名称与内容，再按需调整分类和启用状态。

<Frame caption="将独立的地点、组织或规则整理成条目，并按需启用。">
  ![世界书中按条目组织雾港、旧邮局与灯塔等设定](/images/screenshot/world-info-editor.png)
</Frame>

每个条目尽量围绕一个概念，名称保持清晰，内容说明适用范围和限制。Agent 查阅时，比起宽泛的“世界观大全”，独立的规则或地点更容易定位。

你也可以在会话中通过`@`引用具体条目，让 Agent 围绕该设定完成任务。

## 导入世界书

世界书支持通过`.json`文件导入。选择文件并检查预览后，可以选择追加或覆盖：

| 模式 | 行为 |
| :-- | :-- |
| 追加 | 保留当前条目，名称重复时覆盖已有条目 |
| 覆盖 | 删除当前项目世界书中的现有条目，再导入文件内容 |

<Warning>
  覆盖导入会替换现有世界书；追加导入也可能改写同名条目。导入前请检查文件内容与条目名称，并保留需要的备份。
</Warning>

## 与笔记和规则配合

角色资料适合人物信息，世界书适合明确的设定条目，笔记适合自由组织的资料和草稿。需要长期约束 Agent 行为的写作要求，则更适合放在[项目规则](/feature/rules-prompts)中。

这些内容的存在，并不意味着每次请求都会完整塞入模型上下文。重要任务仍应给出明确引用，或要求 Agent 先查阅相关资料，再开始写作。

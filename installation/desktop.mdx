## 选择安装包

| 系统 | Intel/AMD 64 位 | ARM 64 位 | 推荐格式 |
| --- | --- | --- | --- |
| Windows | `win-x86_64` | `win-aarch64` | `-setup.exe` 安装包或 `.zip` 便携版 |
| macOS | `mac-x86_64` | `mac-aarch64` | `.dmg` 安装包或 `.zip` |
| Linux | `linux-x86_64` | `linux-aarch64` | `.AppImage` 或 `.tar.gz` |

你应该根据系统实际架构选择安装包类型，如果不清楚设备的系统架构，可以按照以下步骤查看：

<Tabs>
  <Tab title="Windows">
    按`Win+R`后打开`运行`窗口，输入`msinfo32`并回车。

    在打开的系统信息窗口中，左侧点选`系统摘要`后，在右侧找到`系统类型`字段：

    - 基于 x64 ... → 选择`win-x86_64`
    - 基于 ARM ... → 选择`win-aarch64`
  </Tab>
  <Tab title="Linux">
    在终端中执行：

    ```bash
    uname -m
    ```

    - `x86_64` → 选择`linux-x86_64`
    - `aarch64`或`arm64` → 选择`linux-aarch64`
  </Tab>
  <Tab title="MacOS">
    打开苹果菜单中的`关于本机`，如果显示 Apple 芯片，请选择`mac-aarch64`；如果显示 Intel 处理器，请选择`mac-x86_64`。
  </Tab>
</Tabs>

## 首次启动

首次打开时，你可以安装并启动本地实例，也可以连接已经运行的 OpenFic 服务器。

### 本地实例

按照引导选择运行环境的安装目录和作品数据目录，等待所需组件安装完成后启动。桌面应用和本地实例是两个部分：前者提供窗口与实例管理，后者负责保存数据、处理模型请求并运行 Agent。

安装目录用于保存运行环境，数据目录用于保存作品和配置，请避免让两个目录相互包含。以后更新或重新安装时，也应保留原有数据目录。

### 远程实例

如果你已通过 Docker 或 Python 部署了 OpenFic，可以填写服务器 URL 连接该实例。此时作品保存在远程服务器，桌面端本地数据备份不会代替服务器备份。

<Note>
  0.13.0 未发布：当前仓库支持为连接的实例配置访问密钥。如果远程服务已通过`OPENFIC_AUTH_PASSWORD`开启认证，请填写与服务端一致的密钥；本地实例也可以在桌面端配置访问密钥，以配合[远程隧道](/feature/tunnels)使用。
</Note>

## 数据和备份

默认情况下，桌面版将项目数据保存在系统用户数据目录，而不是应用安装目录；在安装并使用本地实例时，也可以指定自定义数据目录。

| 系统 | 默认数据目录 |
| --- | --- |
| Windows | `%APPDATA%\OpenFic` |
| macOS | `~/Library/Application Support/OpenFic` |
| Linux | `~/.config/OpenFic` |

你也可以在桌面端的数据管理页面中迁移、备份或还原数据。

备份应包含整个数据目录，尤其是用于解密提供商密钥的`.key`文件，更多说明参阅[访问认证与数据备份](/installation/configuration)。

<Warning>
  对于 Windows 版本，建议不要将 **数据/实例目录** 设置在应用安装目录下，否则在执行自动更新时，可能会误清除安装目录下的实例和数据，导致数据丢失。
</Warning>

## 更新

为了确保数据安全，务必在更新前备份数据，以免造成不必要的麻烦。

### 自动更新

<Note>
  仅支持 Windows 版本
</Note>

你可以在页面右上角找`检查更新`按钮，点击后会自动检测是否存在可更新的包体。

在下载完成后，点`重启并更新`后，应用会自动关闭并在后台完成所有更新操作，完成后，窗口会自动打开。

如果使用的是本地实例，那么在启动实例时，会自动识别并更新本地实例至相匹配的版本。

### 手动更新

<Steps>
  <Step title="下载新版本">
    前往 [Github Release](https://github.com/syrizelink/OpenFic/releases/latest) 下载最新与你的系统架构相匹配的安装包
  </Step>
  <Step title="安装">
    完全关闭旧版桌面应用，然后安装或解压新版本至原路径
  </Step>
  <Step title="启动">
    启动应用，等待本地实例完成更新即可
  </Step>
</Steps>

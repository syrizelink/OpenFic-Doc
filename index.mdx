**OpenFic** 是一款专为小说创作打造的跨平台、用户友好、AI Native 的一站式 Vibe Writing 工具，构建设定、设计角色、定制工作流，让Agent适应你的写作流程，而非反之。

</Note>

## 快速开始

你可以通过以下方式快速安装 OpenFic

<Tabs>
  <Tab title="Docker">
    ```shellscript
    docker run -d -p 8000:8000 -v "openfic:/data" --name openfic ghcr.io/syrizelink/openfic:latest
    ```

    然后打开 [http://localhost:8000](http://localhost:8000) 开始使用
  </Tab>
  <Tab title="pip">
    ```shellscript
    pip install openfic
    openfic serve
    ```

    然后打开 [http://localhost:8000](http://localhost:8000) 开始使用
  </Tab>
  <Tab title="uv">
    ```shellscript
    uvx --python 3.12 openfic@latest serve
    ```

    然后打开 [http://localhost:8000](http://localhost:8000) 开始使用
  </Tab>
  <Tab title="桌面版">
    前往 [Github Release](https://github.com/syrizelink/OpenFic/releases/latest) 下载桌面应用，在你的系统上原生运行，而无需额外步骤。
  </Tab>
</Tabs>

## 开始创作

安装完成后，你需要先[连接模型提供商](/getting_started/provider)，再[创建模型](/getting_started/model)并选择默认模型。随后创建一个项目，即可在工作区中编辑正文并与 Agent 协作，参阅[开始使用 OpenFic](/getting_started/first_step)。

如果你已经有自己的写作流程，可以通过[智能体](/feature/agent)、[技能](/feature/skill)以及[规则与提示词](/feature/rules-prompts)逐步调整，而不必一次配置所有功能。

对于长篇作品，可以使用[角色与世界书](/feature/worldbuilding)管理设定，通过[索引](/feature/index)检索章节，并利用[摘要](/feature/summary)与[上下文管理](/feature/context)控制长会话的上下文占用。

部署到其他设备前，建议先了解[访问认证与数据备份](/installation/configuration)。需要在外出时访问本地实例，可以继续参阅[远程隧道](/feature/tunnels)。

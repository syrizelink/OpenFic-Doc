---
title: "开始使用 OpenFic"
---

在完成安装且配置了 [提供商](/getting_started/provider) 和 [模型](/getting_started/model) 后，就可以正式开始探索 OpenFic 的一切功能了！

你可以遵循以下步骤来开始你的第一个章节：

## 创建项目

进入主页，你可以在左上角找到`新建项目`和`导入`按钮。

在 OpenFic 中，项目是组织一切内容的单元，章节、设定、角色以及Agent会话，所有都与项目相关联且由项目派生。

在新建项目时，你可以选择设定封面、名称和简介，以便于你在项目众多时快速找到它们。

## 认识工作区

从主页点击刚刚创建的项目以进入工作区。

应用会记住你最近打开的三个工作区并将它们显示在应用左侧的主边栏中，以便你可以快速访问。

工作区采用了与多数 IDE 应用类似的三栏式布局，你可以自由调整边栏的尺寸以符合自己的习惯，接下来我们逐个介绍不同部分的作用：

### 列表区

列表区是位于左侧的区域，在这里你可以以列表形式直观的看到所有章节和笔记，并对他们进行创建、删除、移动或排序等操作。

默认的，系统会为新建的项目自动创建一个不包含任何章节的卷。

在 OpenFic 中，所有章节都以分卷形式的二级结构组织，如果你不需要多卷结构，在一个卷内存放所有章节即可。

在列表区上方，你可以找到包含多个功能按钮的工具栏，点击`新建章节`后，将会自动创建一个名为`未命名章节`的章节，你可以右键它以重命名为你想要的章节名。

在列表区上方，你可以找到切换按钮，能够在`章节`和`笔记`之间切换，二者是含义不同的内容单元，你可以按需将不同类型的内容存放到对应位置，一般而言：

- 章节：存放小说的正文内容，卷-章结构
- 笔记：任何内容，随意记录，多级分类结构

无论是章节还是笔记，Agent 都能够读取它们，以帮助你完成工作。

在章节或笔记众多时，你可以在工具栏找到`搜索`按钮，善用该功能，能够帮助你快速检索到相关信息，并点击跳转打开对应位置。

如果需要批量的将章节导出到外部，除了复制粘贴以外，你还可以在工具栏找到`导出`按钮，并选择所需的章节，将它们以TXT格式导出为文件。

### 编辑区

编辑区是位于中央的，占据部分最多的区域，你可以在这里打开笔记和章节页签并编辑它们。

其中，笔记是 Markdown 格式的，你可以输入格式标记，系统会自动识别并将它们转换为特殊样式。

现在你可以点击列表区刚刚新建的`未命名章节`将其打开。

在编辑区，顶栏标题和章节名/笔记名是同步的，因此如需修改它，直接在标题处进行编辑即可。

在正文部分随意输入一些内容，稍后会触发自动保存，不过为了保证数据不丢失，时常使用`Ctrl+S`手动保存也是很有必要的。

### 会话区

在这里，你可以与 Agent 交互，与它一起协同完成写作任务。

默认情况下，有两种主智能体(模式)可供选择：

- Build：执行大多数任务
- Plan：先规划后组织子 Agent 完成工作，为系统写作任务设计

确定要使用的模式并选用模型后，就可以开始与 Agent 交互了。

Agent 能够使用工具对章节、笔记、角色和世界书进行检索、查阅和修改。

或是进行网络搜索（需配置）并读取网页以获取互联网的最新信息。
